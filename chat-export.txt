### 2. Controller + routes
[](https://github.com/Mohamedtamer1265/Task2-ai-assisted-coding-lab4.2#2-controller--routes)
Implement these three controller functions and wire them in `server/src/routes/evaluations.js`:

methodpathfunctionsuccess responsePOST`/api/evaluations``createEvaluation``201` `{ evaluation: <document> }`GET`/api/evaluations``getAllEvaluations``200` `{ evaluations: [...] }`GET`/api/evaluations/:id``getEvaluation``200` `{ evaluation: <document> }`
- For `GET /api/evaluations/:id` on a valid id that does not exist, respond `404` with `{ message: 'Evaluation not found' }`.
- Pass unexpected errors to `next(err)`, as the User controller does.

### 3. The summary endpoint
[](https://github.com/Mohamedtamer1265/Task2-ai-assisted-coding-lab4.2#3-the-summary-endpoint)
Implement `getEvaluationSummary` and wire it as `GET /api/evaluations/summary?seminarCode=SM101`. It returns:

```
{ "seminarCode": "SM101", "averageScore": <number>, "evaluationCount": <integer> }
```

- Compute it with `Evaluation.aggregate()`: `$match` on `seminarCode`, then `$group` with `$avg` of `score` and `$sum: 1`. Loading documents with `find()` and averaging in JavaScript does not count.
- If nothing matches, return the requested `seminarCode` with `averageScore: 0` and `evaluationCount: 0`.
- If the `seminarCode` query parameter is missing, respond `400` with `{ message: 'seminarCode is required' }`.
- `/summary` must be reachable and must not be handled by `/:id`.
